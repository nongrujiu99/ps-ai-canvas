# Photoshop 2024+ UXP 面板

此目录是 Photoshop 25.0 起的 UXP 可加载插件目录。使用 UXP Developer Tool 的 **Add Plugin** 选择 `manifest.json`，然后 **Load**，在 Photoshop 插件菜单打开“PS AI 画布”。需要同时运行 [`service`](../../service/README.md) 本地服务。当前没有真实 Photoshop 测试，因此 25.0 及后续版本均标为未验证。

“按选区打开 PS AI 画布”命令会打开面板并检查当前选区；在面板确认后才发起可能计费的生成请求。能否直接绑定 Photoshop 快捷键需在目标版本实测。原生画布右键菜单没有自定义入口。

首版只支持 RGB 8 位、512–4096 像素的图像编辑。结果先在面板预览；应用时创建新像素图层，选区灰度用作图层蒙版。若文档在等待期间变化，或扩图结果尺寸与画布不一致，会把结果单独打开，避免错误地覆盖原图。UI 和真实图层位置仍需按版本检查。
