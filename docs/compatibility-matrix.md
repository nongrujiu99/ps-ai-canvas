# Photoshop 兼容性记录

最后更新：2026-11-10。`目标` 表示包的声明范围；`未测试` 表示尚未在该版本 Photoshop 中加载并走完整任务。

| Photoshop | 主机实现 | 目标 | 实机状态 | 说明 |
| --- | --- | --- | --- | --- |
| 2018（19.x） | CEP 8 | 是 | 未测试 | 需检查面板加载、ExtendScript 导出与蒙版回填。 |
| 2019（20.x） | CEP 9 | 是 | 未测试 | 同上。 |
| 2020（21.x） | CEP 9 | 是 | 未测试 | 同上。 |
| 2021–2023（22–24.x） | CEP | 是 | 未测试 | 过渡期沿用旧版面板。 |
| 2024（25.x） | UXP | 是 | 未测试 | Imaging/Selection API 与命令入口需验证。 |
| 2025 及以后 | UXP | 是 | 未测试 | 需逐版复核加载、网络权限、图层及快捷入口。 |

本地服务的模拟任务、连接码防跨来源调用和 Windows 凭据读写已有自动化测试。未使用真实百炼 API Key，也未在 Photoshop 中执行付费编辑。大图局部编辑已实现带上下文裁剪；整图重绘和扩图仍要求画布在 512–4096 像素范围内。四向扩图只在模型输出尺寸与比例精确一致时修改原 PSD，否则把结果打开为独立文档，以免错位。真实 Photoshop 中的画布扩展和图层对齐尚未验证。

实机验收记录应至少包含：安装版本和构建号、文档颜色/位深、普通选区及羽化、手动透明边缘扩图、四向滑杆扩图、预览后回填、等待期间切换文档、撤销、服务离线与 API 错误。未测版本不改写为“兼容”。
