# Legacy Photoshop CEP Host Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver the Photoshop 2018–2023 panel and quick command for masked editing, expansion, whole-image editing, and text-to-image.

**Architecture:** A CEP panel owns the small UI and talks to the `/v1` local service from the service plan. ExtendScript performs Photoshop document reads, non-destructive exports, and guarded result application. The panel keeps temporary files out of the PSD and only applies a chosen result after explicit acceptance.

**Tech Stack:** CEP HTML/CSS/ES5-compatible JavaScript, `CSInterface`, ExtendScript JSX, Windows PowerShell packaging.

**Spec:** `docs/superpowers/specs/2026-11-10-ps-ai-fill-design.md`

## Global Constraints

- Target host: Photoshop 19–24 (2018–2023), Windows; verify each installed version before marking it compatible.
- Main modes: `选区编辑 / 扩图 / 生成`; whole repaint is under Advanced.
- Default candidates: 1; prompt optional for masked fill and expansion, required for whole repaint and text-to-image.
- Ordinary canvas selection edits inside; rectangular selected transparent border routes to expansion; ambiguous selection asks the user.
- Preview first, then add a new layer or new document; never overwrite original pixels.
- A quick command may be assigned a Photoshop shortcut; no promise of adding to the native canvas right-click menu.

## Review Focus

- Feathered selection must survive as a grayscale Photoshop layer mask although the cloud mask is binary (Task 1 test/check).
- An absent selection in masked mode must stop before exporting or billing (Task 2 test).
- A switched document or changed canvas size while waiting must open the result separately (Task 3 test).
- A malformed or quoted Windows path must pass safely across `evalScript` (Task 1 test).
- A network error must leave the panel actionable and the PSD untouched (Task 2 test).

### Task 1: CEP-to-Photoshop Bridge

**Files:**
- Create: `hosts/cep/CSXS/manifest.xml`, `hosts/cep/js/csinterface-adapter.js`, `hosts/cep/js/host.js`, `hosts/cep/jsx/bridge.jsx`, `hosts/cep/test/host.test.js`, `hosts/cep/test/bridge-checklist.md`

**Interfaces:**
- Produces: `host.inspect() -> Promise<Context>` with `documentId`, `historyId`, `width`, `height`, `colorMode`, `depth`, `selectionBounds`.
- Produces: `host.capture(operation, options) -> Promise<Capture>` with PNG data URLs for composite and selection mask, plus `Context` snapshot and a local grayscale selection-mask file.
- Produces: `host.apply(resultPng, capture) -> Promise<{ documentId, layerId }>`; `host.openSeparate(resultPng) -> Promise<{ documentId }>`.
- Consumes: `/v1` job request shape from `2026-11-10-local-service.md`.

- [ ] **Step 1: Write adapter tests** using a fake `CSInterface.evalScript` callback for path quoting, JSON errors, and a preserved document snapshot.
- [ ] **Step 2: Run** `node --test hosts/cep/test/host.test.js`; confirm failure.
- [ ] **Step 3: Implement** the JavaScript adapter and CEP manifest with Photoshop 19 as minimum host version.
- [ ] **Step 4: Implement** JSX inspection, temporary composite export, cloud-binary mask export, separate grayscale selection-mask preservation, and guarded new-layer import. Use temporary duplicate documents so a failed export leaves the original untouched.
- [ ] **Step 5: Run** the adapter tests; expect all pass. Complete the versioned manual checklist for selection feather, empty selection, unsupported mode, and new layer placement on any available PS 2018–2023 installation; mark unavailable versions unverified.
- [ ] **Step 6: Commit** the bridge and its tests/checklist.
