# Modern Photoshop UXP Host Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver the same AI editing workflow as the CEP host in Photoshop 2024 and later, using supported UXP imaging and command APIs.

**Architecture:** A UXP panel and command entrypoint talk to the same `/v1` local service as the legacy host. Photoshop's Imaging API supplies composite and selection pixels; the service normalizes them and returns both preview PNG and raw result bytes. Document changes run inside Photoshop's modal execution and create new pixel layers/masks after a snapshot check.

**Tech Stack:** UXP manifest v5, Photoshop UXP Imaging API, `batchPlay` for gaps in the DOM, built-in `fetch`, Node.js tests with Photoshop API fakes.

**Spec:** `docs/superpowers/specs/2026-11-10-ps-ai-fill-design.md`

## Global Constraints

- Target host: Photoshop 25+ (2024 onward), Windows; mark only tested versions compatible.
- Reuse the service plan's `/v1` contract and the CEP host's three-mode interaction design.
- Capture and apply in RGB 8-bit only; dispose of PhotoshopImageData after use.
- No unapproved automatic extra generation, PSD overwrite, or assumption that a Photoshop canvas right-click item can be added.
- A UXP command offers the fast entry; a keyboard shortcut is enabled only where that Photoshop version supports one.

## Review Focus

- A Photoshop document switched while the job runs must not receive the result (Task 2 test).
- A selection's gray feather values must survive as a layer mask (Task 1 test).
- ImageData must be disposed after capture or import, including failures (Task 1 test).
- A 16/32-bit, CMYK, or unsupported early Photoshop version must fail before upload (Task 1 test).
- If the local service is not running, the panel must show a setup/retry action, not lose the user's prompt (Task 2 test).

### Task 1: UXP Photoshop Bridge

**Files:**
- Create: `hosts/uxp/manifest.json`, `hosts/uxp/src/photoshop-host.js`, `hosts/uxp/src/imaging-adapter.js`, `hosts/uxp/test/photoshop-host.test.js`

**Interfaces:**
- Produces: `host.inspect() -> Promise<Context>` using `document.id`, dimensions, mode, depth, selection bounds, and history state.
- Produces: `host.capture(operation, options) -> Promise<Capture>` with `{ kind: "rgba", width, height, dataBase64 }` composite and `{ kind: "gray8", width, height, dataBase64 }` selection, plus snapshot.
- Produces: `host.apply(rawResult, capture) -> Promise<{ documentId, layerId }>`; `host.openSeparate(rawResult) -> Promise<{ documentId }>`.
- Consumes: raw result route `GET /v1/results/:id/:index/raw` from the service plan.
