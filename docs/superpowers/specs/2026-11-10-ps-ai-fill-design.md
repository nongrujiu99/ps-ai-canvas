# Photoshop 2018 至新版 AI 填充插件设计

日期：2026-11-10

状态：用户已同意当前方案，进入实施计划

## 目的

在 Photoshop 2018、2019、2020 及后续版本的面板内完成选区填充、四向扩图、文生图和重绘。用户能用提示词和选区控制内容，预览结果后再写入文档。首版使用阿里云百炼；服务接入层保留增加 Comfly 等供应商的空间。

## 已确定的选择

- 首版接阿里云百炼。`wanx2.1-imageedit` 负责选区填充、重绘和扩图；`wan2.7-image` 负责文生图。两者配置同一北京地域的百炼凭据和业务空间。
- 兼容端采用 CEP HTML 面板和 ExtendScript，目标为 PS 19–24（2018–2023）；其中 PS 19–21 是最初指定版本，PS 22–24 覆盖 UXP 早期图像接口不足的过渡期。新版端另做 UXP 面板和命令入口，目标从 PS 25（2024）起。两端共享操作流程、服务协议与视觉设计，但各自实现 Photoshop 文档、选区和图层桥接；不能假定 CEP 包可直接用于未来所有版本。版本分界依据 Adobe 的 API 资料，实际兼容性仍需逐版验证。
- 独立的本地服务负责图片预处理、请求阿里云、轮询任务、下载结果。面板不直接保存 API Key。首版按当前 Windows 工作环境设计安装包。
- 结果先预览；用户接受后才修改 Photoshop 文档。修改以新图层、图层蒙版和可撤销的画布操作完成。

## 曾考虑的路线

1. **CEP 直接请求 Comfly `gpt-image-2`。** 模型统一，但精确遮罩需要其官转组透传参数，扩图还需插件预制扩展画布。用户希望先选择更直接的接入路线。
2. **CEP + 本地服务 + 阿里云百炼（选定）。** 阿里云对局部遮罩和四向扩图有专用参数；需要两个图像模型和两个请求适配器，但功能映射清楚。
3. **CEP + 自建云后端。** 适合多人共用、统一计费和托管密钥；首版个人使用没有必要增加服务器运维。

## 功能行为

| 操作 | 用户输入 | 云端调用 | 接受结果后的行为 |
| --- | --- | --- | --- |
| 选区填充 | Photoshop 选区、可选提示词；空提示词使用自然补全指令 | `wanx2.1-imageedit`，`description_edit_with_mask` | 只把选区结果作为新图层内容，原有像素保留 |
| 局部重绘 | Photoshop 选区、必填提示词 | 同上 | 新图层加选区蒙版，可继续在 PS 手工修边 |
| 整图重绘 | 当前画面、必填提示词、模型支持的修改幅度 | `wanx2.1-imageedit`，`description_edit` | 生成完整结果新图层 |
| 扩图 | 上、下、左、右各自的比例，或已经手工扩出的规则透明边缘；提示词可选 | `wanx2.1-imageedit`，`expand` | 扩大当前画布并把生成的新边缘放在新图层，保留原图层；若画布已扩大，则回填现有空白边缘 |
| 文生图 | 提示词、尺寸、数量 | `wan2.7-image` | 创建新文档；已有文档时可选择作为新图层放入 |

填充与局部重绘使用同一云端能力，区别在默认指令和面板文案。选区导出为与输入图同尺寸的黑白遮罩：白色是修改区域，黑色是保留区域。云端遮罩按接口要求二值化；同时保存 Photoshop 原始选区的灰度蒙版，接受结果时用于新图层，因此羽化和抗锯齿边缘仍由 PS 控制。扩图四向比例范围依据接口限制为 1.0–2.0；超出范围时面板提示，不隐式拆成多次付费任务。如果用户先在 PS 手工扩大画布并选中规则的透明边缘，插件从非透明原图区域推算扩展方向和比例，仍调用 `expand`；用户无需写提示词，插件提供自然延伸场景的默认指令。模型的局部重绘空提示词仅明确用于删除小物体，不把大块透明区域的空提示词视为可靠扩图方式。`seed` 和生成数量在模型支持时显示。修改幅度仅用于 `description_edit` 等官方明确支持的模式，不展示在局部遮罩模式。

## 用户流程与边界

面板首屏保持一条主要路径：选择“选区编辑 / 扩图 / 生成” → 输入画面描述 → 生成预览。“选区编辑”统一承载填充与局部重绘：留空时由插件提供自然补全指令，输入描述时按描述替换或重绘选区。整图重绘可在“高级设置”中把编辑范围改为“整张画面”，此时提示词必填，并显示模型支持的修改幅度。文档与选区状态以一行摘要展示；扩图方向只在扩图模式出现。候选数量、随机种子、输出尺寸、编辑范围和修改幅度等条件参数收进默认折叠的“高级设置”。候选数量默认 1 张，增加候选或重新生成会发起新的云端请求。结果出现后才显示候选图与“应用”操作，面板不常驻展示整张 Photoshop 画布。

快捷入口读取当前选区后自动分流：画布内普通选区进入局部编辑；已经手工扩画布形成的规则透明边缘进入扩图。两种条件同时出现、选区形状不规则或无法识别透明原图边界时，面板要求用户明确选择，不猜测并上传错误区域。旧版通过 Photoshop 脚本菜单及自定义快捷键启动；新版通过 UXP 命令入口启动，快捷键能力逐版验证。主面板不增加额外的顶层模式。

1. 设置北京地域的 API Key 和业务空间 ID。密钥只由本地服务读取，存入当前 Windows 用户的系统凭据存储；不写入 PSD、日志或插件源码。
2. 选择操作。面板检查活动文档、选区、图像尺寸和必要参数；导出临时合成图。局部操作使用包含周边内容的工作区域，避免把整张大型 PSD 都上传。临时处理不改动原文档。
3. 本地服务把图像和遮罩以 Base64 发送给百炼。图像编辑的 HTTP 调用是异步的，提交后查询任务。结果 URL 有时效；服务收到结果后立即下载到本地临时目录。
4. 面板展示最多四张候选图、状态和错误。用户可以重试、取消本地等待或接受一张。额外候选和重试前提示将发起新的请求；取消等待不承诺撤销已提交的云端计费任务。
5. 接受时再次核对目标文档及其尺寸。若用户在等待期间切换或大幅修改文档，结果改为打开新文档，避免覆盖错误位置。写入 Photoshop 的结果作为新图层，可通过历史记录撤销。

输入限制以模型接口为准。编辑模型要求输入边长在 512–4096 像素且文件不超过 10 MB。首版的局部编辑可裁出带上下文的区域处理；整图重绘和扩图若超限，面板明确提示需缩小工作图，不暗中降低原图分辨率。首版处理 RGB 8 位、原图可见区域不透明的文档；允许手工扩图后四边形成规则透明边缘。任意形状的透明洞、CMYK、16/32 位、索引色和原本就透明的底图在导出前明确提示，不修改原文档。首版不支持批处理、自动分块扩图、Mac 安装包或其他云供应商。

## 结构

旧版：`CEP 面板 → ExtendScript 桥接 → 临时图像/遮罩 → 本地服务 → 阿里云任务 → 本地结果 → CEP 预览 → ExtendScript 新图层`

新版：`UXP 面板/命令 → Photoshop UXP API → 临时图像/遮罩 → 同一本地服务 → 阿里云任务 → 本地结果 → UXP 预览 → Photoshop UXP API 新图层`

UXP 端以 PS 25 起提供的 Imaging API、选区 API 和模态写入流程实现；PS 22–24 由 CEP 兼容端覆盖。旧版快捷入口可通过脚本菜单与用户设置的快捷键实现；新版使用 UXP 命令入口，快捷键能否直接绑定取决于目标版本的 Photoshop 支持情况，逐版验证。两端都不承诺在 Photoshop 画布原生右键菜单插入自定义项。

本地服务的供应商适配接口按 `generate`、`editMasked`、`editWhole`、`expand` 四种能力定义。未来加入 Comfly 时只替换请求、任务查询和结果解析，不重写 Photoshop 的选区与图层逻辑。

## 验收标准

- 在 PS 2018–2023 中通过 CEP 面板完成四类操作；在 PS 2024 及后续目标版本中通过 UXP 面板完成同样操作。目标版本逐一实机验证，未安装或未测试的版本不标为已兼容。
- 选区外原图像素不因填充或局部重绘改变，结果位于可单独隐藏和删除的新图层。
- 四个方向可独立设定扩图比例，预览后才扩大 PSD 画布。
- API 失败、超时、模型尺寸不符、无选区、文档切换都有明确提示，原文档不被半成品修改。
- API Key 不出现在源码、日志、请求错误文案或 PSD 中。

## 待用户确认的默认值

- 首版只打包 Windows 安装方式；若需要 macOS，应在实现前调整安装和密钥方案。
- 文生图默认创建新文档；其他操作默认把接受的结果写入当前文档的新图层。
- 首版只处理 RGB 8 位且原图可见区域不透明的图像；支持手工扩画布形成的规则透明边缘，并保留选区羽化边缘。其他颜色模式和任意透明底处理可在后续版本扩展。

当前工作环境未发现已安装的 Photoshop 2018–2020。实现时可以验证协议、图像处理和打包结构；各目标版本 Photoshop 的面板加载、选区读取、预览和回填仍需要在装有相应版本的机器上完成。
